### 📋 Schéma Détaillé

#### `utilisateur` - Gestion des utilisateurs
```sql
CREATE TABLE utilisateur (
    id_utilisateur INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(255) UNIQUE NOT NULL,
    mot_de_passe VARCHAR(255) NOT NULL,
    nom VARCHAR(100),
    telephone VARCHAR(20),
    adresse VARCHAR(255),
    date_inscription TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### `offre_emploi` - Annonces de poste
| Colonne | Type | Taille | Contraintes | Description |
|---------|------|--------|-------------|-------------|
| **id_offre** | INT | - | PK, AUTO_INCREMENT | Identifiant unique |
| **titre** | VARCHAR | 255 | NOT NULL | Ex: "Développeur Java" |
| **description** | TEXT | - | NOT NULL | Description complète |
| **type_contrat** | VARCHAR | 100 | NOT NULL | CDI, CDD, Freelance, Stage, Alternance |
| **statut_offre** | VARCHAR | 50 | NOT NULL | ACTIVE, ARCHIVED |
| **date_publication** | DATE | - | NOT NULL | Date de création |
| **id_utilisateur** | INT | - | FK, NOT NULL | Référence utilisateur |
| **lieu** | VARCHAR | 255 | - | Ville/Région |
| **work_preference** | VARCHAR | 50 | - | Remote, Hybrid, On-Site |

#### `critere_offre` - Critères d'une offre
| Colonne | Type | Taille | Contraintes | Description |
|---------|------|--------|-------------|-------------|
| **id_critere** | INT | - | PK, AUTO_INCREMENT | Identifiant unique |
| **id_offre** | INT | - | FK, NOT NULL | Référence offre |
| **niveau_experience** | VARCHAR | 255 | - | Ex: "3-5 ans" ou "Junior" |
| **niveau_etude** | VARCHAR | 255 | - | Ex: "Bac+5" ou "Master" |
| **responsibilities** | TEXT | - | - | • Tâche 1<br/>• Tâche 2 |
| **competences_requises** | TEXT | - | - | • Skill 1<br/>• Skill 2 |

### 🔗 Relations
```
utilisateur (1) ──────────────── (N) offre_emploi
                                       │
                                       │ (1)
                                       │
                                       └──── (N) critere_offre
```

- **Relationships** : Suppression en cascade si offre supprimée
- **Intégrité** : Référential integrity en place
- **Indexation** : Sur id_utilisateur, statut_offre, date_publication

### 💾 Données Exemples


### 🚀 Guide d'Installation Pas à Pas

#### **Étape 1️⃣ : Cloner le Projet**

```bash
# Clone depuis GitHub
git clone https://github.com/yourusername/VOS-Desktop.git

# Naviguez au dossier
cd VOS-Desktop/off/off
```

#### **Étape 2️⃣ : Configurer MySQL**

**Option A : Import du Schéma**
```bash
# Se connecter à MySQL
mysql -u root -p

# Créer la base de données
CREATE DATABASE vos_platform DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE vos_platform;

# Importer le schéma
SOURCE database_schema.sql;
```

**Option B : Script SQL Direct**
```sql
CREATE TABLE utilisateur (
    id_utilisateur INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(255) UNIQUE NOT NULL,
    mot_de_passe VARCHAR(255) NOT NULL,
    nom VARCHAR(100)
);

CREATE TABLE offre_emploi (
    id_offre INT PRIMARY KEY AUTO_INCREMENT,
    titre VARCHAR(255) NOT NULL,
    description TEXT,
    type_contrat VARCHAR(100),
    statut_offre VARCHAR(50) DEFAULT 'ACTIVE',
    date_publication DATE,
    id_utilisateur INT,
    lieu VARCHAR(255),
    FOREIGN KEY (id_utilisateur) REFERENCES utilisateur(id_utilisateur)
);

CREATE TABLE critere_offre (
    id_critere INT PRIMARY KEY AUTO_INCREMENT,
    id_offre INT,
    niveau_experience VARCHAR(255),
    niveau_etude VARCHAR(255),
    responsibilities TEXT,
    competences_requises TEXT,
    FOREIGN KEY (id_offre) REFERENCES offre_emploi(id_offre)
);
```

#### **Étape 3️⃣ : Configurer config.properties**

Éditer `src/main/resources/config.properties` :

```properties
# 🗄️ Database Configuration
db.url=jdbc:mysql://localhost:3306/vos_platform
db.user=root
db.password=your_mysql_password
db.driver=com.mysql.cj.jdbc.Driver

# 🤖 AI Provider Selection
ai.provider=gemini  # Options: gemini, claude, groq
ai.api.key=YOUR_API_KEY_HERE

# 📧 Email Configuration (optional)
mail.smtp.host=smtp.gmail.com
mail.smtp.port=587
mail.from=your-email@gmail.com
mail.password=your-app-password
```

#### **Étape 4️⃣ : Installer les Dépendances**

```bash
# Clean et build complet
mvn clean install -DskipTests

# Affichera :
# [INFO] BUILD SUCCESS ✅
```

#### **Étape 5️⃣ : Compiler le Projet**

```bash
# Compilation Java
mvn compile

# Affichera :
# [INFO] Compiling 15 source files to target/classes
```

#### **Étape 6️⃣ : Lancer l'Application**

```bash
# ✨ Démarrer VOS Desktop
mvn javafx:run
```

**Succès !** 🎉 L'application devrait démarrer
